# Ahorrapp 

Aplicación sencilla de control financiero personal hecha con **Ionic, React y JavaScript**.

## Instalación
1. Instalar node.js 
https://nodejs.org/dist/v22.21.0/node-v22.21.0-x64.msi

2. Escribir los siguientes comandos en la terminal: 
npm install
npm start
Abrir en el navegador: http://localhost:3000
