# Feature 003 — Financial Dashboard

## Objetivo

Convertir la pantalla principal en un resumen financiero accionable.

## Información principal

El dashboard deberá mostrar:

1. saldo actual;
2. ingresos del período;
3. gastos del período;
4. ahorro neto;
5. tasa de ahorro;
6. principales categorías;
7. últimas transacciones;
8. progreso de metas;
9. estado de presupuestos.

## Selector temporal

Debe permitir:

- mes actual;
- mes anterior;
- período personalizado.
